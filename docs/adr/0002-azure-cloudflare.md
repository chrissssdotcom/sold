# ADR-0002: Azure hosting, Cloudflare edge and email

- Status: Accepted
- Date: 2026-09-30
- Deciders: Sold engineering (Platform/SRE)

## Context

ADR-0001 chose Azure Container Apps, PostgreSQL Flexible Server, Azure Managed Redis and Key Vault for hosting and Cloudflare for the edge, and said every vendor capability is an unverified assumption until recorded here. This ADR records what was **checked against current sources on 2026-09-30**, what could not be checked, and where reality differs from the plan. Nothing in `ops/terraform` was applied: there are no cloud credentials in the build environment. Terraform validity was checked with the real providers (see "How this was verified").

## How this was verified

Three tiers, stated per claim in the tables below:

- **Source docs**: the official documentation source files, fetched from their public repositories (`MicrosoftDocs/azure-docs`, `hashicorp/terraform-provider-azurerm`, `hashicorp/web-unified-docs`, `cloudflare/cloudflare-docs`, `cloudflare/terraform-provider-cloudflare`, `Azure/login`) and Microsoft's retirement feed. The rendered sites (`learn.microsoft.com`, `developers.cloudflare.com`, `registry.terraform.io`) were **blocked by the sandbox egress proxy**, so the rendered pages were not opened.
- **Provider schema**: `terraform init` with the real providers (`azurerm` 5.7.0, `cloudflare` 5.26.0, `random` 3.9.1, `tls` 4.4.1), `terraform validate`, `terraform test` (mock providers) under Terraform 1.16.4 and OpenTofu 1.13.0. A resource name or attribute that validates exists in that provider version.
- **Web search excerpt**: a search summary of a `learn.microsoft.com` page whose source file was not reachable. Reliable enough to design against, not enough to sign a contract: **re-read the linked page before apply**. Marked `search`.
- **UNVERIFIED**: could not be checked here. Marked `UNVERIFIED - verify before apply`.

## Deviations from the plan, and what they cost

1. **azurerm is v5, not v4.** Providers are no longer auto-registered (bootstrap registers the needed ones), Key Vault requires `rbac_authorization_enabled`, the DNS zone link takes a zone id. All encoded and validated.
2. **Edge certificates.** Container Apps managed certificates do not work behind Cloudflare, so each environment gets a Cloudflare **Origin CA certificate** (15-year default, 30 days for previews) stored as a Key Vault secret and bound to the app as a custom domain in "Full (strict)" mode. Three things in that chain are **UNVERIFIED - verify on first apply**: Container Apps accepting a PEM (certificate then key) from a Key Vault secret with content type `application/x-pem-file`; the `asuid.<host>` TXT verification for a custom domain that is proxied; and the Origin CA validity values.
3. **Cache-Tag purge is not Enterprise-only.** Good news, but Free-plan rate limits (5 requests/min) mean invalidation must batch by tag and tolerate 429.
4. **Waiting Room is a plan feature.** The module keeps it off by default; `event-scale` sizing assumes the customer is on Business or Enterprise. Scheduled events need the Enterprise advanced add-on.
5. **Email**: SMTP is the default transport, Cloudflare Email Sending is optional (Beta).
6. **Two images, not one.** ADR-0001 says web and worker are one image; the Dockerfile builds separate `web` and `worker` targets. `release.json` gained optional `workerImageDigest` and `migrateImageDigest`; a `migrate` Dockerfile target is **PENDING(phase-0)** (until then the migrate job needs an image that can migrate).
7. **Authentication modes are pragmatic for now.** PostgreSQL uses password authentication with the password generated and held only in Key Vault (Entra administrators are also configured); Managed Redis has access keys enabled (Key Vault). Both flip to Entra-only when the adapters support token auth (PENDING(phase-7) and PENDING(phase-4)). Service Bus is Entra-only from day one.
8. **PgBouncer is absent on Burstable**, so ephemeral and dev environments connect directly; connection budgets there are smaller.
9. **Redis cannot be paused**, so it is excluded from ephemeral and dev, and stage keeps billing while paused.

## Consequences

- Every vendor-specific line is in `ops/terraform` or an adapter; swapping SMTP providers or dropping Cloudflare features is configuration.
- Costs are bounded structurally (scale to zero, Burstable, no Redis/Service Bus in ephemeral, TTL, budgets), but the Container Apps free grant is shared, so per-environment cost is **not** attributable from the invoice alone: use the tags and `sold env:cost`.
- A production incident on a stopped-then-restarted database is avoided by design (nightly pause is idempotent), but a paused dev/stage environment still pays for storage, Redis (stage), Log Analytics and the Key Vault.
